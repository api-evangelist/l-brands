# L Brands (l-brands)
L Brands was a Fortune 500 specialty retail holding company best known for Victoria's Secret, PINK, and Bath & Body Works. In 2021 the company split into two independent publicly traded companies, with Bath & Body Works, Inc. retaining the original NYSE listing and Victoria's Secret & Co. spun off as a standalone retailer. The L Brands brand is no longer in active use; this repository preserves the historical corporate record. No public developer API has been documented.
